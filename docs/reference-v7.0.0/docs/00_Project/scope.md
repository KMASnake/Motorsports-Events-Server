# Périmètre v6.1

La plateforme centralise, corrige, complète manuellement et publie des calendriers de sports mécaniques.
Elle gère les disciplines, championnats, catégories facultatives, saisons, épreuves et sessions.

## Inclus
- données issues de plusieurs fournisseurs ;
- données entièrement manuelles lorsqu'aucun fournisseur n'existe ;
- rapprochement futur entre données manuelles et données fournisseur ;
- corrections par champ, audit, versionnement et publication ;
- API publique et API d'administration ;
- interface d'administration sombre validée.

## Hors périmètre initial
- résultats sportifs détaillés, classements pilotes/équipes et chronométrage en direct ;
- billetterie et diffusion vidéo ;
- exploitation commerciale des marques des championnats.
