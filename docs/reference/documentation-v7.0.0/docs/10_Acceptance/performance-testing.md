# Tests de performance

## Mesures
- latence API p50/p95/p99 ;
- débit ;
- durée d'une synchronisation ;
- consommation CPU/mémoire ;
- taille des files ;
- temps de publication ;
- temps de restauration.

## Scénarios
- lecture publique nominale ;
- pic de lecture ;
- synchronisation simultanée de plusieurs fournisseurs ;
- import historique ;
- conflit massif ;
- correction en lot ;
- endurance sur 24 h minimum selon environnement.
