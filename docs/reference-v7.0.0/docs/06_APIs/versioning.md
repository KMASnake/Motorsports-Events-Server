# Versionnement

La version majeure figure dans l'URL : `/api/v1`.

Compatible :
- ajout d'un champ optionnel ;
- ajout d'un endpoint ;
- ajout d'un filtre.

Incompatible :
- suppression ou renommage de champ ;
- changement de type ou de sémantique ;
- changement de structure d'erreur.

Tout changement incompatible exige une nouvelle version majeure.
