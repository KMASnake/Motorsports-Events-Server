# Priorité des valeurs

Ordre de priorité :

1. Override actif validé.
2. Décision éditoriale canonique sans override temporaire.
3. Valeur canonique issue d'une décision de fusion.
4. Observation fournisseur prioritaire.
5. Observation fournisseur secondaire.
6. Valeur absente.

## Règle
La priorité s'applique champ par champ.

## Interdit
Un fournisseur ne peut jamais désactiver implicitement une correction active.
