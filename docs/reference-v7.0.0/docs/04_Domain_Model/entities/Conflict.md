# Conflict

## Rôle
Matérialise un désaccord nécessitant décision ou règle.

## Identité
Identifiant interne ; objet + champ + ensemble d'observations.

## Attributs essentiels
- Type
- Gravité
- Statut
- Valeurs candidates

## Relations
- Référence un objet canonique et des observations

## Cycle de vie
Ouvert → En analyse → Résolu / Ignoré

## Invariants
- Une résolution indique la décision et sa justification

## Événements de domaine
- ConflictDetected
- ConflictResolved
