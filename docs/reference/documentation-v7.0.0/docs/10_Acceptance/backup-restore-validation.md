# Validation sauvegarde et restauration

## Test
1. Créer des données, corrections et audit.
2. Exécuter une sauvegarde.
3. Altérer ou supprimer l'environnement de test.
4. Restaurer.
5. Vérifier intégrité, permissions, corrections, historiques et snapshots.
6. Mesurer RPO et RTO.
7. Consigner les écarts.

Une sauvegarde non restaurée en test n'est pas considérée comme validée.
