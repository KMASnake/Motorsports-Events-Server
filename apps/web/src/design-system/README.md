# MEDS — Motorsports Events Design System

Phase 1.1 pose les fondations visuelles obligatoires : tokens, grille d'espacement,
rayons, typographie, états, palette métier et structure d'application.

Toute nouvelle interface doit utiliser `tokens.css`. Les valeurs hexadécimales,
espacements ou rayons codés directement dans les composants sont interdits sauf
exception documentée.
