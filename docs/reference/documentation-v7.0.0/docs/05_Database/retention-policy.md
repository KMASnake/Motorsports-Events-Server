# Conservation et purge

## Conservation longue
- Données canoniques publiées.
- Corrections et overrides.
- Audit.
- Snapshots publiés.
- Correspondances d'identifiants.

## Conservation configurable
- Payloads bruts volumineux.
- Journaux techniques détaillés.
- Résultats intermédiaires de matching.

## Purge
Une purge ne doit jamais supprimer les éléments nécessaires à :
- expliquer une valeur publiée ;
- reconstruire une décision ;
- répondre à un audit ;
- comprendre une correction.
