# Conventions API

- Préfixe public : `/api/v1`
- Préfixe administration : `/api/v1/admin`
- Type : `application/json`
- Encodage : UTF-8
- Chemins au pluriel.
- Champs JSON en `camelCase`.
- Identifiants opaques.
- Dates au format RFC 3339.

## Statuts principaux
200, 201, 202, 204, 400, 401, 403, 404, 409, 422, 429, 500, 503.
