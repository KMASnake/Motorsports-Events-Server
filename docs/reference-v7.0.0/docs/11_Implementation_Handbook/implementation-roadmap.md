# Roadmap d'implémentation v6.1

Chaque incrément est vertical : migration, domaine, application, API, UI, tests et documentation.
Le premier jalon doit démontrer deux cas : une saison sans catégorie (Formule 1) et une saison avec
catégorie (Moto2 sous MotoGP). Le deuxième jalon ajoute la création manuelle et le mapping ultérieur.
