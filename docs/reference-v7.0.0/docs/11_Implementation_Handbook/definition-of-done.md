# Definition of Done v6.1

Une fonctionnalité est terminée lorsque :
- les invariants championnat/catégorie/saison sont testés ;
- le cas `categoryId = null` est couvert ;
- l'OpenAPI, les DTO et migrations sont synchronisés ;
- l'interface respecte les maquettes v6.1 ;
- les tests unitaires, intégration et E2E passent ;
- l'audit et les permissions sont vérifiés ;
- aucune provenance fournisseur ne fuite dans le texte public ;
- la documentation est mise à jour.
