# Vision produit v6.1

Motorsports Events fournit un catalogue fiable et indépendant des fournisseurs pour tous les sports
mécaniques. L'organisation par discipline permet une navigation claire ; le championnat reste l'objet
central ; la catégorie n'est utilisée que lorsqu'elle apporte une information réelle.

La plateforme doit rester utile même en l'absence totale d'API grâce à la création manuelle, puis
permettre un rapprochement propre lorsqu'un fournisseur devient disponible.
