# Intégration aux conflits

## Cas créant un conflit
- correction incompatible avec un autre champ ;
- second override concurrent ;
- valeur corrigée impossible selon le domaine ;
- nouvelle donnée fournisseur contredisant une correction sensible ;
- cible fusionnée ou archivée.

## Résolution
- conserver la correction ;
- remplacer la correction ;
- révoquer ;
- fusionner les corrections ;
- déplacer la correction vers la nouvelle cible ;
- rejeter la nouvelle observation.
