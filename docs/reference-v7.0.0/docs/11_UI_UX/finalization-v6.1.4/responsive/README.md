# Responsive — v6.1.4

## Breakpoints officiels

| Nom | Largeur | Comportement |
|---|---:|---|
| desktop-xl | >= 1440 px | Référence pixel-perfect 1536×1024 |
| desktop | 1200–1439 px | Sidebar fixe, contenu fluide |
| tablet-landscape | 900–1199 px | Sidebar compacte 72 px |
| tablet-portrait | 600–899 px | Navigation en tiroir |
| mobile | < 600 px | Navigation en tiroir, cartes empilées |

## Règles

- Aucune donnée critique ne doit disparaître.
- Les tableaux deviennent scrollables horizontalement sous 900 px.
- Les KPI passent de 4 colonnes à 2, puis 1.
- Les boutons destructifs restent visibles mais ne doivent jamais être seuls sans libellé.
- Les modales utilisent 90vw sous 900 px et 100vw sous 600 px.
- Les graphiques conservent légende, unités et texte alternatif.
