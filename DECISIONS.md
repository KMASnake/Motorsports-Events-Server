# Décisions — compatibilité

La source active des décisions permanentes est `docs/handbook/DECISIONS.md`, complétée par les ADR de `docs/handbook/architecture/`.

Les anciens ADR de l'architecture Python restent conservés dans `docs/decisions/` comme historique. Ils ne décrivent pas l'état courant lorsqu'ils divergent du Handbook ou des ADR actifs.

L'historique de l'ancien contenu de ce fichier reste disponible dans Git.
