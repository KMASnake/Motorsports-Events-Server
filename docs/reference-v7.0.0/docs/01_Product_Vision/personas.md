# Personas

## Administrateur
Configure les fournisseurs, lance ou planifie les synchronisations, corrige les
données et surveille la qualité.

## Opérateur éditorial
Vérifie les événements, applique des corrections et valide les conflits.

## Client API
Consomme des données normalisées sans gérer les différences entre fournisseurs.

## Développeur / Codex
Implémente le produit à partir de la documentation, des règles métier, des
contrats et des critères d'acceptation.
