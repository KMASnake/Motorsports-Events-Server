# Workflow Git

## Branches
- `main` : production ;
- `develop` facultative selon stratégie ;
- branches courtes `feature/*`, `fix/*`, `chore/*`.

## Pull requests
- petite taille ;
- description claire ;
- tests associés ;
- checklist remplie ;
- revue obligatoire ;
- CI verte avant fusion.

## Interdit
- commit direct non exceptionnel sur `main` ;
- secrets ;
- fichiers générés inutiles ;
- historique réécrit sur branche partagée.
