# ADR — Lot 4.2

## ADR-4.2-001 — Mutations optimistes
Déplacement et redimensionnement utilisent une mutation optimiste avec rollback.

## ADR-4.2-002 — Mois par défaut
La vue Mois reste l’entrée principale du module Événements.

## ADR-4.2-003 — Source d’état unique
Toutes les vues utilisent le même état, les mêmes filtres et le même client API.

## ADR-4.2-004 — Alternative au drag-and-drop
Toute action drag-and-drop reste disponible via le formulaire.

## ADR-4.2-005 — Conflits non bloquants
Le lot 4.2 signale les conflits simples sans bloquer la sauvegarde.
