# Conflits

## Exemples
- dates différentes au-delà du seuil ;
- circuits incompatibles ;
- statut annulé contre confirmé ;
- deux objets canoniques candidats ;
- changement important d'identité.

## Gravité
- info
- warning
- blocking

## Résolution
- choisir une valeur ;
- conserver la valeur canonique ;
- créer une correction ;
- fusionner deux entités ;
- ignorer avec justification.

Un conflit identique déjà ouvert ne doit pas être dupliqué.
