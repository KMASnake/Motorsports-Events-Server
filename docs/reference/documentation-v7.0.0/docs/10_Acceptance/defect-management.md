# Gestion des anomalies

## Sévérité
- critique : perte de données, faille grave, service inutilisable ;
- majeure : parcours critique bloqué ;
- moyenne : contournement acceptable ;
- mineure : défaut cosmétique ou gêne limitée.

## Cycle
new → confirmed → assigned → fixed → retest → closed
ou rejected / accepted_risk / deferred.

Toute acceptation de risque doit être motivée et datée.
