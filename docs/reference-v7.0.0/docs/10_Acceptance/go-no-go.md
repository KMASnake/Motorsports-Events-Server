# Décision go/no-go

## Go
Tous les critères de sortie sont atteints ou les risques résiduels sont
formellement acceptés.

## Go conditionnel
Déploiement autorisé avec conditions, surveillance renforcée et plan de
correction daté.

## No-go
Un défaut critique, une restauration non validée, une faille grave ou un
parcours critique invalide interdit la mise en production.
