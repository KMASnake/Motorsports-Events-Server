# Politique de reprise

## Rejouable
- timeout ;
- erreur réseau ;
- 429 ;
- 502, 503, 504 ;
- verrou temporairement indisponible.

## Non rejouable automatiquement
- authentification invalide ;
- schéma fournisseur incompatible ;
- données métier systématiquement invalides ;
- configuration absente.

## Limites
Nombre maximal de tentatives, durée maximale et délai cumulé sont configurables
par fournisseur.
