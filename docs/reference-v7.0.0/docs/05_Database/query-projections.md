# Projections de lecture

Pour éviter de surcharger le modèle transactionnel, Codex peut créer des vues
ou projections dédiées :

- upcoming_sessions
- championship_calendar
- provider_health
- unresolved_conflicts
- active_overrides
- synchronization_summary

Ces projections sont dérivées et reconstruisibles. Elles ne deviennent pas la
source de vérité.
