# Corrections temporaires

Une correction peut avoir :
- une date de début d'effet ;
- une date de fin ;
- une politique d'expiration ;
- une valeur de retour prévue.

## Exemple
Forcer temporairement un statut en `postponed` jusqu'à confirmation officielle.

## Règle
Une correction expirée ne disparaît pas ; seul son override devient inactif.
