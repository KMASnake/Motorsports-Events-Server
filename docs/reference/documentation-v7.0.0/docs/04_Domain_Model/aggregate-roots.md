# Agrégats v6.1

## Discipline Aggregate
Racine : Discipline. Contrôle son code, son statut et l'ordre d'affichage.

## Championship Aggregate
Racine : Championship. Contrôle ses catégories et les règles de rattachement.

## Season Aggregate
Racine : Season. Garantit la présence du championnat et la cohérence de la catégorie facultative.

## Event Aggregate
Racine : Event. Contrôle la cohérence temporelle de ses sessions.

## Correction Aggregate
Racine : Correction. Contrôle le workflow et l'override actif.
