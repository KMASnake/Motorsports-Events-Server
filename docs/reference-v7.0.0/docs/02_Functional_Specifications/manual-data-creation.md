# Création manuelle des données

## Assistant
1. Choisir ou créer une discipline.
2. Choisir ou créer un championnat.
3. Choisir « Aucune catégorie » ou sélectionner/créer une catégorie.
4. Créer la saison.
5. Créer l'épreuve et son circuit/lieu.
6. Ajouter une ou plusieurs sessions.
7. Vérifier puis publier.

## Exigences
- le fournisseur n'est jamais obligatoire ;
- les objets créés manuellement utilisent les mêmes validations que les objets synchronisés ;
- l'origine `manual` est technique et ne doit pas apparaître dans le texte public ;
- un mapping fournisseur peut être ajouté plus tard sans changer l'identité canonique ;
- la publication partielle est interdite si une session obligatoire est invalide.
