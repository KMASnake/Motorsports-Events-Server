# Archives documentaires

Ce répertoire conserve les preuves, audits, recettes, handoffs et documents de gouvernance clôturés qui ont une valeur historique durable.

Aucun fichier sous `docs/archive/` ne définit l'état courant du projet. Pour l'état opérationnel, lire [docs/handoff/PROGRESS.json](../handoff/PROGRESS.json).

## Arborescence

- [handoff-history/](handoff-history/) — documents historiques issus de `docs/handoff/` et `docs/handover/` ;
- [handbook-history/](handbook-history/) — anciennes recettes ou documents de gouvernance remplacés.

Les chemins d'origine sont conservés autant que possible sous les sous-arborescences d'archive afin de préserver le contexte et d'éviter les collisions de noms.

Pour les contrats actifs, consulter [docs/handoff/](../handoff/README.md). Pour les règles permanentes, consulter le [Project Handbook](../../PROJECT-HANDBOOK.md).
