# Discipline

## Rôle
Regroupe les championnats selon leur famille de sports mécaniques.

## Référentiel initial
Automobile, Moto, Karting, Camion, Drift, Rallye Raid, Motocross, Speedway.

## Attributs
`id`, `code`, `name`, `description`, `icon`, `displayOrder`, `status`.

## Relations
Possède plusieurs championnats.

## Invariants
Code unique et immuable ; une discipline utilisée ne peut être supprimée physiquement.
