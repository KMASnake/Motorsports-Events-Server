# Validation finale

Le projet est considéré prêt à implémenter lorsque :
- toutes les sections critiques sont présentes ;
- les dépendances sont explicites ;
- les contrats sont testables ;
- les règles de sécurité sont actionnables ;
- la recette est définie ;
- les procédures de livraison et rollback existent ;
- les responsabilités sont identifiées.

La v5.8 atteint cet objectif documentaire.
