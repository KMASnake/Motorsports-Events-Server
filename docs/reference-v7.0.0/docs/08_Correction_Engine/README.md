# Moteur de correction — v5.5

Le moteur de correction permet de modifier de manière traçable une valeur
canonique erronée sans bloquer les autres champs fiables provenant des
fournisseurs.

## Principes
- Correction au niveau du champ.
- Priorité explicite sur les observations fournisseurs.
- Historique complet.
- Validation contrôlée.
- Réversion possible.
- Aucun écrasement silencieux.
- Audit de toute décision.
