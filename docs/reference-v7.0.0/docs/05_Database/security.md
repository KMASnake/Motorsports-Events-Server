# Sécurité des données

- Les secrets fournisseurs sont stockés hors des tables métier.
- Les données sensibles sont chiffrées au repos selon les capacités de
  l'infrastructure.
- Les sauvegardes sont protégées et testées.
- Les journaux ne doivent contenir ni token, ni clé API, ni mot de passe.
- Les actions d'administration sont auditées.
