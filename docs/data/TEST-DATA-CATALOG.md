# Catalogue des données de test

Le générateur déterministe produit 12 championnats, 40 circuits dans huit
pays et 96 événements couvrant passé/futur, publié/brouillon, annulé/reporté
et chevauchements. Utilisation :

```bash
npm run data:generate -- --seed=lot-4.2
```

Toutes les identités sont synthétiques et les descriptions indiquent la seed.
