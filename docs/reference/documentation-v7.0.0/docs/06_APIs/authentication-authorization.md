# Authentification et autorisation

Toutes les routes `/admin` exigent une identité authentifiée.

Permissions proposées :
- catalog.read
- catalog.write
- providers.read
- providers.manage
- synchronizations.read
- synchronizations.run
- corrections.read
- corrections.submit
- corrections.approve
- audit.read
- users.manage

La solution définitive d'authentification sera figée en v5.6.
