# Écrans opérationnels UI v6.1.2

Cette livraison complète quatre pages de la console d’administration : **Circuits**, **API**, **Observabilité** et **Journaux**.

Les références respectent le canevas officiel 1536×1024, la sidebar 215 px, la topbar 71 px, les tokens v6.1 et les états de composants v6.1.

## Contenu
- `screens/` : références PNG réellement générées ;
- `prototype/` : prototype HTML/CSS/JS navigable ;
- `specifications/` : règles fonctionnelles et visuelles par écran ;
- `acceptance-tests/` : critères Gherkin ;
- `contracts/` : contrats de données frontend attendus.

## Règle impérative
Aucun nom de fournisseur ou d’API ne doit apparaître dans les descriptions publiques d’événements. Les informations de provenance restent strictement administratives.
