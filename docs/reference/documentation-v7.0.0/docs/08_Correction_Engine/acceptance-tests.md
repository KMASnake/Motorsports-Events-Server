# Acceptation du moteur de correction v6.1

- correction du nom d'une discipline ;
- correction du championnat d'une saison ;
- ajout puis retrait d'une catégorie facultative ;
- rejet d'une catégorie appartenant à un autre championnat ;
- correction d'une date d'épreuve ou de session ;
- réversion sans perte d'historique ;
- priorité de la correction sur une nouvelle observation fournisseur.
