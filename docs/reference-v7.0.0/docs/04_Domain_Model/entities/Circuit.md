# Circuit

## Rôle
Représente une installation sportive stable.

## Identité
Identifiant interne ; nom canonique et alias.

## Attributs essentiels
- Nom
- Configuration
- Coordonnées
- Fuseau

## Relations
- Situé dans un lieu et un pays
- Accueille plusieurs épreuves

## Cycle de vie
Actif → Inactif → Archivé

## Invariants
- Un circuit conserve ses alias historiques

## Événements de domaine
- CircuitCreated
- CircuitAliasAdded
