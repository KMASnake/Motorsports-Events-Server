# Checklist de revue de code

- [ ] Le besoin est compris.
- [ ] Le domaine reste indépendant.
- [ ] Les erreurs sont traitées.
- [ ] Les entrées sont validées.
- [ ] Les permissions sont vérifiées.
- [ ] Aucun secret n'est présent.
- [ ] L'idempotence est respectée.
- [ ] Les transactions sont cohérentes.
- [ ] Les logs sont utiles et sûrs.
- [ ] Les tests couvrent le comportement.
- [ ] La documentation est mise à jour.
- [ ] Les migrations sont sûres.
- [ ] La performance est acceptable.
