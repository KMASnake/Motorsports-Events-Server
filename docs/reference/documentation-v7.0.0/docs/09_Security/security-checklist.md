# Checklist sécurité avant production

- [ ] TLS valide
- [ ] MFA administrateurs
- [ ] Secrets hors Git
- [ ] Comptes minimaux
- [ ] Base non exposée
- [ ] Sauvegarde et restauration testées
- [ ] Journaux et alertes configurés
- [ ] Scans de dépendances actifs
- [ ] Conteneurs non root
- [ ] CORS restrictif
- [ ] SSRF testé
- [ ] Webhooks signés
- [ ] Permissions vérifiées
- [ ] Procédure d’incident disponible
