# Planification

## Types
- planification périodique ;
- lancement manuel ;
- rattrapage ;
- synchronisation ciblée ;
- resynchronisation historique.

## Règles
- éviter les départs simultanés inutiles ;
- permettre une fenêtre horaire ;
- respecter la durée moyenne ;
- empêcher le chevauchement interdit ;
- prioriser les événements proches dans le temps.
