# Accessibilité et utilisabilité

Vérifier :
- navigation clavier ;
- labels ;
- contrastes ;
- messages d'erreur compréhensibles ;
- focus ;
- responsive ;
- lisibilité des tableaux ;
- confirmation des actions destructives ;
- prévisualisation des corrections en lot ;
- compréhension des statuts de synchronisation.

Les écarts doivent être classés et planifiés.
