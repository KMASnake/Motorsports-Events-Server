# Jeux de données de test

## Jeux minimaux
- championnat complet ;
- saison avec plusieurs manches ;
- séances normales ;
- course sprint ;
- qualification sprint ;
- annulation ;
- report ;
- changement de circuit ;
- fournisseur partiellement indisponible ;
- conflits multi-fournisseurs ;
- correction active ;
- correction révoquée ;
- données historiques.

## Règles
- données reproductibles ;
- identifiants stables ;
- génération scriptée ;
- nettoyage automatique ;
- anonymisation si source réelle.
