# Environnements de test

## Types
- local développeur ;
- intégration continue ;
- intégration partagée ;
- préproduction ;
- environnement de reprise.

## Règles
- configuration proche de la production en préproduction ;
- secrets dédiés ;
- aucune donnée personnelle réelle non anonymisée ;
- fournisseurs simulés lorsque nécessaire ;
- versions et paramètres enregistrés dans le rapport.
