# Services de domaine v6.1

- `SeasonOwnershipPolicy` : valide championnat et catégorie facultative.
- `ManualCatalogService` : crée la hiérarchie canonique sans fournisseur.

- `EntityMatchingService` : propose les correspondances.
- `CanonicalMergeService` : arbitre les valeurs par champ.
- `CorrectionReversionEvaluator` : détecte une correction potentiellement devenue inutile.
