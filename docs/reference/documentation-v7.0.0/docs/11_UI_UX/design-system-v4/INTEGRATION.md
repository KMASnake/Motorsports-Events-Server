# Intégration dans le dépôt existant

1. Créer la branche `docs/design-system-v4`.
2. Copier le dossier `docs/` à la racine du dépôt.
3. Conserver les fichiers existants et résoudre les doublons manuellement.
4. Ajouter les six maquettes dans `docs/design-system/assets/mockups/`.
5. Vérifier les liens relatifs.
6. Commiter avec le message :
   `docs(ui): bootstrap design system v4 sprint 1`
7. Ouvrir une Pull Request vers la branche de documentation active.
