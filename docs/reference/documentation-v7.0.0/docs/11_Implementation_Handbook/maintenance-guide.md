# Guide de maintenance

## Quotidien
- surveiller erreurs, files, quotas, synchronisations et alertes.

## Hebdomadaire
- vérifier sauvegardes ;
- examiner dépendances ;
- traiter conflits ;
- contrôler capacité.

## Mensuel
- tester restauration partielle ;
- revoir accès ;
- analyser performance ;
- mettre à jour la documentation.

## Trimestriel
- exercice d'incident ;
- rotation de secrets selon politique ;
- revue des ADR et risques.
