# Suite de non-régression

## Obligatoire à chaque livraison
- création et mise à jour d'événements ;
- absence de doublons ;
- traitement des annulations ;
- course sprint incluse ;
- qualification sprint exclue du mode course ;
- corrections protégées ;
- réversion auditée ;
- pagination ;
- erreurs normalisées ;
- permissions ;
- sauvegarde et restauration ;
- publication conditionnelle.

Chaque défaut corrigé doit ajouter un test de non-régression.
