# Règles permanentes Codex

Avant toute modification :
1. lire `PROJECT-HANDBOOK.md` ;
2. lire `CODEX.md` et `PROJECT-STATUS.json` ;
3. lire `docs/handoff/PROGRESS.json` ;
4. lire `docs/handbook/DECISIONS.md` et tous les ADR permanents ;
5. lire la documentation du lot dans `docs/handoff/`.

Toute évolution permanente doit mettre à jour le Handbook, DECISIONS.md, CHANGELOG.md et l'ADR concerné.

Une fusion dans `main`, une CI verte ou une validation technique ne remplace
jamais une validation explicite de l'utilisateur.
