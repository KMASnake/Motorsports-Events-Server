# Sécurité du moteur

- secrets via coffre ou variables sécurisées ;
- rotation sans redéploiement complet si possible ;
- TLS obligatoire ;
- validation stricte des URLs ;
- protection SSRF ;
- taille maximale de réponse ;
- délais d'attente ;
- aucune exécution de contenu fournisseur ;
- redaction des données sensibles dans les logs.
