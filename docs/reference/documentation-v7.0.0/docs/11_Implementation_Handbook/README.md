# Manuel final d'implémentation — v5.8

Ce dossier explique comment transformer la documentation fonctionnelle et
technique en produit opérationnel.

## Principes
- livrer par incréments verticaux ;
- garder les contrats stables ;
- automatiser les validations ;
- protéger les données et secrets ;
- documenter toute décision structurante ;
- ne jamais contourner les règles de correction, d'audit ou d'idempotence.
