# Glossaire contrôlé v6.1

- **Discipline** : regroupement de premier niveau. Valeurs initiales : Automobile, Moto, Karting,
  Camion, Drift, Rallye Raid, Motocross, Speedway.
- **Championnat** : compétition stable administrée et publiée, par exemple Formule 1 ou MotoGP.
- **Catégorie** : subdivision facultative d'un championnat, par exemple Moto2 ou Hypercar.
- **Saison** : édition datée d'un championnat ; elle peut être directe ou rattachée à une catégorie.
- **Épreuve** : rendez-vous d'une saison, par exemple Grand Prix de France.
- **Event** : nom technique anglais de l'entité Épreuve.
- **Session** : séance planifiée d'une épreuve : essais, qualification, sprint, course, etc.
- **Donnée manuelle** : donnée canonique créée sans observation fournisseur.
- **Mapping fournisseur** : correspondance entre une ressource externe et une ressource canonique.
- **Correction** : décision explicite qui remplace une valeur canonique au niveau d'un champ.
