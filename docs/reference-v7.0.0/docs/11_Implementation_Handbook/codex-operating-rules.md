# Règles d'exécution pour Codex

- ne pas inventer un contrat absent ;
- suivre les ADR ;
- conserver la terminologie documentaire ;
- ajouter un test pour chaque défaut ;
- ne pas supprimer une protection sans ADR ;
- ne pas modifier plusieurs domaines sans justification ;
- produire des commits petits et vérifiables ;
- signaler toute ambiguïté bloquante ;
- ne jamais introduire de secret ;
- conserver la compatibilité des API.
