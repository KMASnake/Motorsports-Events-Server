# Critères d'entrée et de sortie

## Entrée
- version candidate identifiée ;
- migrations appliquées ;
- environnement stable ;
- données de test disponibles ;
- exigences gelées pour la campagne ;
- défauts bloquants connus documentés.

## Sortie
- aucun défaut critique ouvert ;
- défauts majeurs acceptés explicitement ou corrigés ;
- parcours critiques validés ;
- seuils de performance atteints ;
- restauration testée ;
- rapport final signé ;
- décision go/no-go consignée.
