# Checklist sécurité des données de test

- [ ] environnement différent de `production` ;
- [ ] base temporaire locale et isolée ;
- [ ] dump absent de Git ;
- [ ] utilisateurs, sessions et tokens supprimés ;
- [ ] clés API, OAuth et providers supprimées ;
- [ ] webhooks et notifications neutralisés ;
- [ ] aucun domaine e-mail réel ;
- [ ] aucune URL de production ;
- [ ] vérification bloquante réussie ;
- [ ] snapshot supprimé après usage.
