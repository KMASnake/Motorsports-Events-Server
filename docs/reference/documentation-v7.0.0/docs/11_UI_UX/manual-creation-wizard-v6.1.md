# Assistant de création manuelle

1. Discipline — sélectionner ou créer.
2. Championnat — sélectionner ou créer dans la discipline.
3. Catégorie — option « Aucune catégorie » présélectionnée ou création/sélection.
4. Saison — libellé, année, dates, statut.
5. Épreuve — nom, numéro, dates, circuit/lieu.
6. Sessions — tableau dynamique, type, début, fin, statut.
7. Vérification et publication — résumé hiérarchique et validation atomique.

La création conserve les données de brouillon entre les étapes. La validation finale est transactionnelle.
