# Corrections en lot

## Cas d'usage
- correction de fuseau ;
- renommage cohérent ;
- déplacement de plusieurs séances ;
- correction d'un circuit sur une épreuve.

## Règles
- prévisualisation obligatoire ;
- validation de chaque cible ;
- transaction globale ou stratégie documentée ;
- rapport détaillé ;
- possibilité de révocation par lot ;
- audit individuel et audit de groupe.

## Interdit
Appliquer silencieusement une correction en lot sans résumé d'impact.
