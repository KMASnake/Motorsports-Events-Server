# Contrat d'interface

Les maquettes validées dans `docs/ui-reference/validated-mockups` constituent
la référence visuelle officielle.

Une page est acceptée lorsque :

- la fidélité visuelle mesurée est au moins de 95 % ;
- tous les états interactifs utiles sont présents ;
- aucun composant équivalent n'est dupliqué hors MEDS ;
- le clavier et le focus visible sont pris en charge ;
- les vues desktop et responsive sont vérifiées ;
- une capture de comparaison accompagne la pull request ;
- `PROGRESS.json` reflète l'état réellement testé.

Le lot 1 ne revendique pas encore ces critères : il prépare les fondations.
