# Politique d'assainissement

Les sports, championnats, circuits, événements, dates et relations peuvent
être conservés. Utilisateurs, contacts, sessions, tokens, clés, webhooks,
notifications, journaux identifiants et credentials providers sont supprimés.
Les identifiants provider des événements sont neutralisés dans la copie de
développement. Aucun appel sortant n'est autorisé depuis la base restaurée.
