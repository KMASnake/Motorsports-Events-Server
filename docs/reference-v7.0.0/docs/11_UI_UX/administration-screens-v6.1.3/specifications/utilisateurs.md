# Écran Utilisateurs

## Objectif
Gérer comptes, invitations, rôles, MFA et suspension.

## Actions
Inviter, modifier les rôles, suspendre/réactiver, révoquer les sessions et réinitialiser le MFA.

## Contraintes
Un super-administrateur ne peut retirer son propre dernier rôle critique. Toute élévation de privilège est auditée.
