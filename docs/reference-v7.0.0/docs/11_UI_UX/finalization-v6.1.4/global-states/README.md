# États globaux

Tous les écrans doivent supporter :

1. chargement initial ;
2. rechargement silencieux ;
3. contenu vide ;
4. aucun résultat après filtrage ;
5. erreur réseau ;
6. erreur serveur ;
7. permission insuffisante ;
8. session expirée ;
9. maintenance planifiée ;
10. mode hors ligne ;
11. données obsolètes ;
12. synchronisation en cours ;
13. succès d’action ;
14. action partiellement réussie ;
15. confirmation destructive.

Chaque état doit fournir :
- un titre ;
- une explication ;
- une action principale ;
- une action secondaire si utile ;
- un code d’erreur ou identifiant de corrélation lorsque disponible.
