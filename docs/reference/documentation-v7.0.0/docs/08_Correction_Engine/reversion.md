# Réversion

## Réversion manuelle
Un utilisateur autorisé révoque l'override et choisit la valeur canonique
suivante.

## Réversion assistée
Le système propose une réversion lorsque :
- la valeur fournisseur converge vers la correction ;
- plusieurs sources fiables convergent ;
- la durée prévue expire ;
- la cause de la correction n'existe plus.

## Réversion automatique
Elle n'est autorisée que si la politique de correction l'autorise explicitement
et si toutes les conditions documentées sont satisfaites.

## Règle
La réversion crée une nouvelle décision, sans effacer la correction initiale.
