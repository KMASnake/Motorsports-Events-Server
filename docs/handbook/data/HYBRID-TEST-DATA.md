# Données hybrides

Conserver les données sportives réalistes, synthétiser les identités, supprimer
les secrets, neutraliser les intégrations, vérifier avant promotion et ne
jamais commiter un dump.

Chaque version candidate possède un jeu reproductible et idempotent couvrant
ses nouvelles fonctions. La recette indique la commande d'injection, les
résultats attendus, les contrôles manuels et le nettoyage de l'environnement.
