# Guide d'exploitation

## Démarrage
- base disponible ;
- migrations appliquées ;
- secrets chargés ;
- files disponibles ;
- healthchecks verts.

## Arrêt
- suspendre nouvelles tâches ;
- terminer ou checkpoint les runs ;
- vider les files si nécessaire ;
- sauvegarder ;
- arrêter proprement.

## Incident
- identifier correlationId ;
- isoler le composant ;
- préserver les preuves ;
- appliquer runbook ;
- documenter.
