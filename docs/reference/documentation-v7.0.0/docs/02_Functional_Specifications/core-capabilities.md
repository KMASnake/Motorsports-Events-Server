# Capacités fonctionnelles principales v6.1

1. Administrer les disciplines de référence.
2. Administrer les championnats et leur rattachement à une discipline.
3. Administrer des catégories facultatives sous un championnat.
4. Créer une saison directement sous un championnat ou sous une catégorie.
5. Administrer les épreuves, sessions, circuits et lieux.
6. Créer manuellement toute la hiérarchie sans fournisseur.
7. Rattacher ultérieurement une donnée manuelle à une ressource fournisseur.
8. Configurer plusieurs fournisseurs et leurs mappings.
9. Exécuter, planifier et reprendre les synchronisations.
10. Conserver les observations brutes et leur provenance.
11. Détecter les correspondances, divergences et conflits.
12. Appliquer et réviser des corrections par champ.
13. Publier une représentation canonique stable.
14. Auditer chaque action humaine et automatique.
