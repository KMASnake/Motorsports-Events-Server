# Stratégie de tests

## Niveaux
- tests unitaires ;
- tests de composants ;
- tests d'intégration ;
- tests de contrats ;
- tests API ;
- tests end-to-end ;
- tests de sécurité ;
- tests de performance ;
- tests de résilience ;
- recette utilisateur.

## Principe
Les tests automatisés couvrent les comportements reproductibles. La recette
utilisateur valide la valeur métier, l'ergonomie et les cas nécessitant un
jugement humain.
