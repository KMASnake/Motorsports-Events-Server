# Validation des corrections v6.1

- la catégorie cible doit appartenir au championnat de la saison ;
- `championshipId` ne peut être nul ;
- `categoryId` peut être nul ;
- déplacer une saison vers un autre championnat réévalue ou retire sa catégorie ;
- déplacer une épreuve conserve ses sessions et déclenche une vérification temporelle ;
- toutes les décisions sont auditées.
