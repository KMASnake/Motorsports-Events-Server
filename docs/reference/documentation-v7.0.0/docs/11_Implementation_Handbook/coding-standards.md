# Conventions de code

## Général
- code lisible avant code compact ;
- fonctions courtes ;
- noms explicites ;
- erreurs typées ;
- pas de logique métier dans les contrôleurs ;
- pas de secret dans le code ;
- pas de dépendance implicite au fuseau local.

## Qualité
- formatage automatique ;
- linting ;
- analyse statique ;
- couverture ciblée ;
- tests de non-régression ;
- suppression du code mort.

## Documentation
Toute API publique, commande, événement métier et décision non triviale doit
être documentée.
