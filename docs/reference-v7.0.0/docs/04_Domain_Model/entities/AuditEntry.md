# AuditEntry

## Rôle
Trace immuable d'une action humaine ou automatique.

## Identité
Identifiant et horodatage monotone.

## Attributs essentiels
- Acteur
- Action
- Cible
- Avant/après
- Corrélation

## Relations
- Peut référencer toute entité

## Cycle de vie
Créée uniquement

## Invariants
- Immuable
- Non supprimable par l'interface standard

## Événements de domaine
- Aucun événement secondaire obligatoire
