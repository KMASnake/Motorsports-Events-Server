# Manuel de migration

1. Inventorier versions, schémas et volumes.
2. Sauvegarder.
3. Tester la migration en préproduction.
4. Mesurer durée et verrouillages.
5. Préparer rollback.
6. Geler les écritures si nécessaire.
7. Appliquer migrations.
8. Vérifier intégrité.
9. Relancer services.
10. Exécuter smoke tests.
11. Surveiller.
12. Clôturer ou restaurer.
