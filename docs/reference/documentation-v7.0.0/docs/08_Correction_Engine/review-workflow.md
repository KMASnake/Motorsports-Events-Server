# Workflow de validation

## Soumission
L'auteur fournit :
- la nouvelle valeur ;
- le motif ;
- les preuves ou références utiles ;
- la durée éventuelle ;
- la politique de réversion.

## Revue
Le réviseur vérifie :
- la validité métier ;
- la cible ;
- la cohérence de type ;
- l'absence de doublon ;
- l'impact sur les publications ;
- les conflits existants.

## Séparation des rôles
Une politique peut interdire à l'auteur d'approuver sa propre correction.
Cette règle devient obligatoire pour les corrections sensibles.
