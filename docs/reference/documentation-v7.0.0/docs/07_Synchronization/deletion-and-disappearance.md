# Disparition et suppression

L'absence d'un objet dans une réponse ne signifie pas automatiquement qu'il a
été supprimé.

## Conditions avant désactivation
- synchronisation complète confirmée ;
- fournisseur déclaré exhaustif ;
- objet absent sur plusieurs runs ;
- aucune correction active contradictoire ;
- période de grâce écoulée.

## Résultat
Préférer `inactive` ou `cancelled` à la suppression physique.
